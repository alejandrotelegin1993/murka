# Мурка ищет дом

8-битная игра про бездомную кошку. Мурка живёт на улице, убегает от дворников, собак, машин и мотоциклов, ищет еду и в конце находит дом. Игра идёт на карманной консоли «ПИКСЕЛЬ-8».

**Играть:** https://alejandrotelegin1993.github.io/murka/

## Пять глав

1. **Двор, утро.** Дворник с метлой и прохожие.
2. **Рынок, день.** Собаки и продавец, который кидается тапками.
3. **Проспект, вечер.** Машины.
4. **Набережная, закат.** Мотоциклы и лужи.
5. **Ночь, дождь.** Всё вместе, а свет только от фонарей.

У Мурки 3 сердца и шкала сытости. Сытость понемногу убывает, еда её пополняет: рыбка, сосиска, молоко и миска от доброй бабушки.

## Управление

| Клавиша | Кнопка консоли | Действие |
|---|---|---|
| ← → / A D | крестовина | бег |
| ↓ / S | крестовина вниз | присесть, пролезть под забором |
| Z / Пробел / ↑ | A | прыжок (держи дольше, чтобы прыгнуть выше) |
| X | B | шипеть: отпугивает собаку или человека рядом |
| Enter | START | старт, дальше |
| C | SELECT | палитра: зелёный экран или цвет |
| Tab | | пауза |
| M | | звук |

Кнопки на корпусе нажимаются мышкой и пальцем, так что играть можно и на телефоне.

## Что внутри

Один файл `index.html` на чистом JavaScript и canvas, без зависимостей. Картинка рисуется в разрешении 192×112 в 4 оттенках и увеличивается ×3. Свой пиксельный шрифт 5×7 с русскими буквами. Уровни собираются из готовых кусков улицы, звук — 8-битные бипы на WebAudio.

Пройденные главы и рекорд сохраняются в браузере.
